# SimpleOptions

``` python
SimpleOptions(spacing=(50, 25))
```

Options for the simple column-based arrangement.

## Parameters

| Name | Type | Description | Default |
|----|----|----|----|
| spacing | tuple\[float, float\] | Horizontal gap between columns and vertical gap between nodes. | `(50, 25)` |
